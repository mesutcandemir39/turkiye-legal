# İcra ve İflas Hukuku

İcra ve İflas Hukuku alanında 13 beceri: borclu savunma stratejisi ve icra suclari, haciz kiymet takdiri ve satis, iflas yollari ve masasi ve 10 tane daha. İlgili mevzuat: 2004 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install icra-iflas-hukuku@turkiye-legal
```
