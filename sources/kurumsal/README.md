# Kurumsal Rehber Kayıt Defteri

Bu dizin, henüz doldurulmamıştır. Amacı, kanun/yönetmelik düzeyinde olmayan ama skill'lerin sıkça atıf yapacağı resmî kurum rehberlerini (KVKK Kurumu rehberleri, BDDK tebliğleri, Rekabet Kurumu kılavuzları vb.) kayıt altına almaktır.

Şema, ilk kayıt eklendiğinde `sources/mevzuat/kanunlar.yaml`'daki desene paralel olarak tanımlanacaktır (Faz 4).
