# Hukuk Felsefesi ve Genel Teori

Hukuk Felsefesi ve Genel Teori alanında 10 beceri: argumantasyon ve altlama, dogal hukuk ve adalet, hak ve yukumluluk teorisi ve 7 tane daha.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install hukuk-felsefesi-genel-teori@turkiye-legal
```
