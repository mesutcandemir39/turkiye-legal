# Basın ve Medya Hukuku

Basın ve Medya Hukuku alanında 12 beceri: basin ceza sorumlulugu, cevap duzeltme tekzip, dava usul gorev yetki ve 9 tane daha. İlgili mevzuat: 4721, 5187, 5237 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install basin-medya-hukuku@turkiye-legal
```
