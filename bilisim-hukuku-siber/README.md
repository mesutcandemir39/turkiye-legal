# Bilişim ve Siber Hukuk

Bilişim ve Siber Hukuk alanında 12 beceri: 5651 icerik erisim engelleme, bilisim suclari tck 243 245, dijital delil elde etme degerlendirme ve 9 tane daha. İlgili mevzuat: 5237, 5651, 6698 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install bilisim-hukuku-siber@turkiye-legal
```
