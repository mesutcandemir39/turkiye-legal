# Spor Hukuku

Spor Hukuku alanında 11 beceri: doping hukuku, federasyon tahkim yargi yolu, spor disiplin hukuku ve 8 tane daha. İlgili mevzuat: 6222, 7405 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install spor-hukuku@turkiye-legal
```
