# Atıf ve Kaynak Hijyeni

Atıf ve Kaynak Hijyeni alanında 10 beceri: atif katmanlari ve kanit degeri, dilden norma yanlis atif onleme, dogrulama kontrol listesi teslim oncesi ve 7 tane daha.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install atif-turk-hukuku@turkiye-legal
```
