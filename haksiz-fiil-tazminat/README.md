# Haksız Fiil ve Tazminat

Haksız Fiil ve Tazminat alanında 12 beceri: dava dilekce ve ihtarname, dava gorev yetki ve ispat, destekten yoksun kalma ve cismani zarar ve 9 tane daha. İlgili mevzuat: 6098 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install haksiz-fiil-tazminat@turkiye-legal
```
