# Hukuki Mütalaa

Hukuki Mütalaa alanında 12 beceri: altlama subsumption teknigi, cikar catismasi ve mutalaa etigi, gorev yetki ve yargi yolu ve 9 tane daha.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install hukuki-mutalaa@turkiye-legal
```
