# Hukuk Bürosu Yönetimi

Hukuk Bürosu Yönetimi alanında 10 beceri: dosya arsiv ve imha, dosya ve sure yonetimi, is yuku ve kalite kontrol ve 7 tane daha. İlgili mevzuat: 1136, 6698 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install hukuk-burosu-yonetimi@turkiye-legal
```

## Beceriler (10)

- `/hukuk-burosu-yonetimi:dosya-arsiv-ve-imha`
- `/hukuk-burosu-yonetimi:dosya-ve-sure-yonetimi`
- `/hukuk-burosu-yonetimi:is-yuku-ve-kalite-kontrol`
- `/hukuk-burosu-yonetimi:kvkk-buro-uyumu`
- `/hukuk-burosu-yonetimi:muvekkil-iletisimi-ve-bilgilendirme`
- `/hukuk-burosu-yonetimi:muvekkil-kabulu-ve-cikar-catismasi`
- `/hukuk-burosu-yonetimi:stajyer-ve-yetkilendirme`
- `/hukuk-burosu-yonetimi:vekalet-sozlesmesi-ve-ucret`
- `/hukuk-burosu-yonetimi:vekalet-ucreti-tahsilat`
- `/hukuk-burosu-yonetimi:zamanasimi-ve-sure-hesabi`
