# Sağlık Hukuku

Sağlık Hukuku alanında 11 beceri: aydinlatilmis onam, ceza sorumlulugu, dava usul gorev yetki ve 8 tane daha. İlgili mevzuat: 1219, 3359, 6098 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install saglik-hukuku@turkiye-legal
```
