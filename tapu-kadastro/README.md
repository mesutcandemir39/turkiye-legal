# Tapu ve Kadastro

Tapu ve Kadastro alanında 11 beceri: el atmanin onlenmesi ve ecrimisil, gorev yetki ve husumet, ipotek ve tasinmaz rehni ve 8 tane daha. İlgili mevzuat: 2644, 3402, 4721 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install tapu-kadastro@turkiye-legal
```
