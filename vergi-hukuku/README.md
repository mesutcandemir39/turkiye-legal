# Vergi Hukuku

Vergi Hukuku alanında 12 beceri: gelir kurumlar vergisi, kdv ve dolayli vergiler, musavir iletisim ve rapor ve 9 tane daha. İlgili mevzuat: 193, 213, 3065, 5520 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install vergi-hukuku@turkiye-legal
```
