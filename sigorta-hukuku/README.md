# Sigorta Hukuku

Sigorta Hukuku alanında 12 beceri: beyan yukumlulugu, can hayat sigortalari, dilekce basvuru taslagi ve 9 tane daha. İlgili mevzuat: 5684, 6102 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install sigorta-hukuku@turkiye-legal
```
