# Tüketici Hukuku

Tüketici Hukuku alanında 12 beceri: abonelik ve suregelen edim, ayipli hizmet denetimi, ayipli mal denetimi ve 9 tane daha. İlgili mevzuat: 6502 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install tuketici-hukuku@turkiye-legal
```
