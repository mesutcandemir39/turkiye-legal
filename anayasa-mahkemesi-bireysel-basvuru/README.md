# AYM Bireysel Başvuru

AYM Bireysel Başvuru alanında 12 beceri: adil yargilanma hakki, basvuru formu ve dilekce, basvuru yollarinin tuketilmesi ve 9 tane daha. İlgili mevzuat: 2709, 6216 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install anayasa-mahkemesi-bireysel-basvuru@turkiye-legal
```
