# Bankacılık Hukuku

Bankacılık Hukuku alanında 11 beceri: banka musteri iletisim risk, banka sirri mahremiyet, bankacilik dava gorev yetki ve 8 tane daha. İlgili mevzuat: 5411, 6098 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install bankacilik-hukuku@turkiye-legal
```
