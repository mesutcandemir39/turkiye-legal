# Dava Dosyası Takibi

Dava Dosyası Takibi alanında 11 beceri: delil dizini ve ispat yuku, dosya ozeti cikarma, durusma hazirlik ve ara karar takibi ve 8 tane daha. İlgili mevzuat: 5271, 6100 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install dava-dosya-takip@turkiye-legal
```
