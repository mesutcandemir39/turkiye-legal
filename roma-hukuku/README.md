# Roma Hukuku

Roma Hukuku alanında 10 beceri: akademik kaynak hijyeni, ayni sahsi hak eskidogmatik, eshya miras kokleri ve 7 tane daha.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install roma-hukuku@turkiye-legal
```
