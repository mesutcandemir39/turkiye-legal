# Kişiler Hukuku

Kişiler Hukuku alanında 10 beceri: ad soyad degistirme, dernekler hukuku, ehliyet ve temsil ve 7 tane daha. İlgili mevzuat: 4721 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install kisiler-hukuku@turkiye-legal
```
