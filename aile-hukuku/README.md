# Aile Hukuku

Aile Hukuku alanında 10 beceri: bosanma sebepleri ve kusur, dilekce ve protokol taslagi, gorev yetki ve usul ve 7 tane daha. İlgili mevzuat: 4721, 6284 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install aile-hukuku@turkiye-legal
```
