# Avukatlık Meslek Kuralları

Avukatlık Meslek Kuralları alanında 11 beceri: avukatin yetkileri guvenceleri, avukatlik temel kavramlar, cikar catismasi ve 8 tane daha. İlgili mevzuat: 1136 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install avukatlik-meslek-kurallari@turkiye-legal
```
