# KVKK Uyum Denetleyici

KVKK Uyum Denetleyici alanında 10 beceri: aktarim ve verbis denetimi, aydinlatma acik riza denetimi, cerez pazarlama uyumu ve 7 tane daha. İlgili mevzuat: 6698 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install kvkk-uyum-checker@turkiye-legal
```
