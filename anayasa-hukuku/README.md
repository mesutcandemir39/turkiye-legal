# Anayasa Hukuku

Anayasa Hukuku alanında 11 beceri: adil yargilanma anayasal, anayasa dilekce basvuru taslagi, aym bireysel basvuru stratejisi ve 8 tane daha. İlgili mevzuat: 2709 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install anayasa-hukuku@turkiye-legal
```
