# Rekabet Hukuku

Rekabet Hukuku alanında 11 beceri: birlesme devralma izni, hakim durum kotuye kullanma, idari para cezasi hesabi ve 8 tane daha. İlgili mevzuat: 4054 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install rekabet-hukuku@turkiye-legal
```
