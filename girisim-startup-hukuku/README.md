# Girişim ve Startup Hukuku

Girişim ve Startup Hukuku alanında 10 beceri: cikis exit rekabet vergi, girisim yapilanmasi cap table, hukuki durum tespiti due diligence ve 7 tane daha. İlgili mevzuat: 6098, 6102 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install girisim-startup-hukuku@turkiye-legal
```
