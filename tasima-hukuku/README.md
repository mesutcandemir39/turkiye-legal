# Taşıma Hukuku

Taşıma Hukuku alanında 11 beceri: cmr uluslararasi tasima, dava usul gorev yetki, gecikme ziya hasar talepleri ve 8 tane daha. İlgili mevzuat: 6102 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install tasima-hukuku@turkiye-legal
```
