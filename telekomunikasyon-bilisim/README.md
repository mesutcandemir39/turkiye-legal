# Telekomünikasyon ve Bilişim

Telekomünikasyon ve Bilişim alanında 12 beceri: abonelik tuketici haklari, btk yaptirim savunma, icerik erisim engelleme 5651 ve 9 tane daha. İlgili mevzuat: 5651, 5809 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install telekomunikasyon-bilisim@turkiye-legal
```
