# Tahkim ve Arabuluculuk

Tahkim ve Arabuluculuk alanında 12 beceri: arabuluculuk anlasma tutanak, dava sarti arabuluculuk, hakem karari iptal davasi ve 9 tane daha. İlgili mevzuat: 4686, 6100, 6325 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install tahkim-arabuluculuk@turkiye-legal
```
