# Ticari İşletme Hukuku

Ticari İşletme Hukuku alanında 10 beceri: cari hesap, fatura teyit ve ticari defterler, haksiz rekabet denetimi ve 7 tane daha. İlgili mevzuat: 6102 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install ticari-isletme-hukuku@turkiye-legal
```
