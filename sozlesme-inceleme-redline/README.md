# Sözleşme İnceleme ve Redline

Sözleşme İnceleme ve Redline alanında 11 beceri: bedel faiz odeme ve uyarlama, cezai sart ve tazminat on belirleme, eksik madde ve bosluk tespiti ve 8 tane daha. İlgili mevzuat: 6098 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install sozlesme-inceleme-redline@turkiye-legal
```
