# Fikri Mülkiyet Davaları

Fikri Mülkiyet Davaları alanında 12 beceri: ceza boyutu marka telif, gorev yetki yargi yolu, hukumsuzluk iptal davalari ve 9 tane daha. İlgili mevzuat: 5846, 6100, 6769 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install fikri-mulkiyet-dava@turkiye-legal
```
