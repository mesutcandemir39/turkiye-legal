# İnfaz Hukuku

İnfaz Hukuku alanında 11 beceri: adli para cezasi infazi, denetimli serbestlik, disiplin ve haklar ve 8 tane daha. İlgili mevzuat: 5275 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install infaz-hukuku@turkiye-legal
```
