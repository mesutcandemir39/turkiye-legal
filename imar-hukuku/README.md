# İmar Hukuku

İmar Hukuku alanında 12 beceri: arazi arsa duzenlemesi dop, imar dava dilekce ve yd, imar para cezalari ve 9 tane daha. İlgili mevzuat: 2709, 3194 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install imar-hukuku@turkiye-legal
```
