# Hukuk Muhakemesi

Hukuk Muhakemesi alanında 11 beceri: cevap replik duplik, dava dilekcesi mimarisi, dava sarti arabuluculuk ve 8 tane daha. İlgili mevzuat: 6100 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install hukuk-muhakemesi@turkiye-legal
```
