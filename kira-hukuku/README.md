# Kira Hukuku

Kira Hukuku alanında 12 beceri: gorev yetki arabuluculuk usul, ispat delil ve zamanasimi, kira bedeli tespit ve artis ve 9 tane daha. İlgili mevzuat: 6098 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install kira-hukuku@turkiye-legal
```
