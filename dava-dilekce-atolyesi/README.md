# Dava Dilekçe Atölyesi

Dava Dilekçe Atölyesi alanında 13 beceri: cevap replik duplik, ceza dilekceleri, dava dilekcesi hmk ve 10 tane daha. İlgili mevzuat: 2577, 5271, 6100 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install dava-dilekce-atolyesi@turkiye-legal
```
