# Bilirkişi Raporu İncelemesi

Bilirkişi Raporu İncelemesi alanında 11 beceri: bilirkisi ret tarafsizlik, celiski eksiklik tespiti, ceza idari bilirkisi ve 8 tane daha. İlgili mevzuat: 6100, 6754 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install bilirkisi-rapor-inceleme@turkiye-legal
```
