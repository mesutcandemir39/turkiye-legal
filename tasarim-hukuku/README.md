# Tasarım Hukuku

Tasarım Hukuku alanında 11 beceri: gorev yetki ve usul, hak sahipligi ve calisan tasarimlari, hukumsuzluk davasi ve 8 tane daha. İlgili mevzuat: 6769 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install tasarim-hukuku@turkiye-legal
```
