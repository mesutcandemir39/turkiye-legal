# Kendini Temsil (Asliye)

Kendini Temsil (Asliye) alanında 11 beceri: cevap dilekcesi ve savunma, dava dilekcesi hazirlama, durusma hazirligi ve on inceleme ve 8 tane daha. İlgili mevzuat: 6100 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install kendini-temsil-asliye@turkiye-legal
```
