# E-Ticaret Hukuku

E-Ticaret Hukuku alanında 11 beceri: araci hizmet saglayici platform, e ticaret kvkk veri, e ticaret sozlesme taslagi ve 8 tane daha. İlgili mevzuat: 6502, 6563, 6698 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install e-ticaret-hukuku@turkiye-legal
```
