# Yapay Zekâ Hukuku

Yapay Zekâ Hukuku alanında 12 beceri: ab yz tuzugu risk siniflandirma, algoritmik seffaflik aciklanabilirlik, dava usul gorev yetki ve 9 tane daha. İlgili mevzuat: 6098, 6698 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install yapay-zeka-hukuku@turkiye-legal
```
