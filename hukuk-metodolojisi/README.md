# Hukuk Metodolojisi

Hukuk Metodolojisi alanında 11 beceri: anayasaya uygun yorum ve temel haklar, durustluk kurali ve hakkin kotuye kullanilmasi, gerekceli hukuki akil yurutme metni ve 8 tane daha. İlgili mevzuat: 4721 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install hukuk-metodolojisi@turkiye-legal
```
