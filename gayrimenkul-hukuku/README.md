# Gayrimenkul Hukuku

Gayrimenkul Hukuku alanında 10 beceri: arsa payi kat irtifaki, dava usul tedbir strateji, el atma ecrimisil ortakligin giderilmesi ve 7 tane daha. İlgili mevzuat: 4721, 6098, 634 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install gayrimenkul-hukuku@turkiye-legal
```
