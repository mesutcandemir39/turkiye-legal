# Telif Hakları

Telif Hakları alanında 11 beceri: baglantili haklar meslek birlikleri, ceza sorumlulugu, dava usul gorev yetki ve 8 tane daha. İlgili mevzuat: 5846 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install telif-haklari@turkiye-legal
```
