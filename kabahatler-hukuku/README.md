# Kabahatler Hukuku

Kabahatler Hukuku alanında 11 beceri: basvuru dilekcesi taslagi, basvuru yolu sulh ceza, idari para cezasi denetim semasi ve 8 tane daha. İlgili mevzuat: 5326 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install kabahatler-hukuku@turkiye-legal
```
