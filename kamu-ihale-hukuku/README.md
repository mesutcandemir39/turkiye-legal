# Kamu İhale Hukuku

Kamu İhale Hukuku alanında 12 beceri: asiri dusuk teklif, ihale iptali ve itirazen sonuc, ihale sozlesmesi 4735 ve 9 tane daha. İlgili mevzuat: 4734, 4735 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install kamu-ihale-hukuku@turkiye-legal
```
