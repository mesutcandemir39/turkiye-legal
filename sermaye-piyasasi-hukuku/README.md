# Sermaye Piyasası Hukuku

Sermaye Piyasası Hukuku alanında 12 beceri: bilgi suistimali iceriden ogrenenler, halka arz ve izahname, idari yaptirim ve iptal davasi ve 9 tane daha. İlgili mevzuat: 6362 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install sermaye-piyasasi-hukuku@turkiye-legal
```
