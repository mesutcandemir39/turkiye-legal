# Enerji Hukuku

Enerji Hukuku alanında 12 beceri: dogal gaz piyasasi, enerji ispat delil, enerji sure zamanasimi ve 9 tane daha. İlgili mevzuat: 4646, 6446 sayılı kanunlar.

## Kurulum

```bash
claude plugin marketplace add https://github.com/mesutcandemir39/turkiye-legal
claude plugin install enerji-hukuku@turkiye-legal
```
